# CodeAlpha Ecommerce Store

A simple full-stack ecommerce website built using:

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## Features

- User Registration & Login
- Product Listing
- Product Search
- Category Filter
- Product Details Page
- Shopping Cart
- Checkout System
- Orders Page
- Responsive Design

## Tech Stack

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Node.js
- Express.js
